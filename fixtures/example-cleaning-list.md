# Example cleaning list

Made-up content, used as the default seed and as the fixture the phase 2 import parser is tested
against. It is not anyone's real cleaning list.

It deliberately exercises every structural feature the parser has to handle: cumulative tiers, a
standalone tier, a whole-home room, group headings, notes, and one three-deep nesting.

Format: `##` headings are Routines, a `Cadence: N days` line sets each Routine cadence,
`**bold**` headings are Rooms, bullets are Tasks, and nested bullets are either further Tasks
(when the parent is a Group heading) or Notes on the parent Task.

---

## Weekly

Cadence: 7 days

**Whole home**

- Run the robot vacuum
  - Clear the floors of anything it can catch on first

**Kitchen**

- Wipe the worktops
- Wipe the hob
- Wipe the fridge doors and handles

**Bathroom**

- Clean the toilet
- Clean the basin
  - Remember behind the storage box
- Rinse dust from behind the washing machine
  - Easiest with the hand shower
  - Aim it at the floor drain

## Fortnightly

Cadence: 14 days
Includes: Weekly

**Hallway**

- Wipe the lower coat rack shelf

**Bedroom**

- Change the sheets
- Bedside table
  - Vacuum around it
  - Wipe the lamp

**Living room**

- Sofa
  - Vacuum underneath and behind it
  - Vacuum under the cushions
- Media unit
  - Wipe the top and back
  - Wipe the cabinet doors
    - Clean off any marks
  - Vacuum behind the television
    - Clean the screen if needed

## Quarterly

Cadence: 91 days
Includes: Fortnightly

**Whole home**

- Wipe the doors and light switches
  - Both sides, the handles, and the top edge

**Kitchen**

- Clean the microwave
- Clean the oven and its glass
- Cupboards and drawers
  - Wipe out the insides
  - Throw away anything past its date

## Twice yearly

Cadence: 182 days
Includes: Quarterly

**Bathroom**

- Clean the shower screen
- Clean the wall and floor tiles
- Mirror cabinet
  - Dust the top
  - Clean the shelves inside

## Yearly

Cadence: 365 days

**Whole home**

- Wash the windows

**Balcony**

- Wash the balcony glazing
